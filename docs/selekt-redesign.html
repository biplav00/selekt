What changes vs today

  • Locator rows stop being identical cards: A uses ledger folios 01–03, B uses CH-01 channel strip with one hero line, C uses L-01 spec blocks.
  • Copy shrinks to a 28–30px icon button with a real copied state — no more full-width buttons per row.
  • Empty states teach: each shows the hover → click → paste loop instead of “No selection”.
  • Mono is quarantined to code + readouts only; UI labels are grotesk/serif so it stops shouting “terminal”.

How to pick

  • 01 Ledger — warmest, most memorable; best if Selekt leans friendly/Playwright-community.
  • 02 Bench — most “tool”: fastest to scan at 320px, tactile switch is hard to miss during a demo.
  • 03 Atelier — most premium; blueprint grid makes dense locator text feel composed, not cramped.

Recommendation

Ship 02 Bench as the panel (scan speed wins in a side panel), steal the rotated BEST stamp from 01 and the spec-table element readout from 03. All three share the same DOM shape, so the React port is one afternoon.
